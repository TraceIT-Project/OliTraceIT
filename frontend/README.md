# Frontend - MCP SaaS

Frontend moderno desarrollado con React + Vite + TypeScript + TailwindCSS.

Inspirado en la arquitectura y diseño de Open-WebUI pero desarrollado desde cero con código propio.

## Características

- ✅ Diseño responsive y moderno
- ✅ Modo oscuro/claro
- ✅ Navegación intuitiva
- ✅ Dashboard con estadísticas
- ✅ Gestión de bots por sector
- ✅ Simulación logística interactiva
- ✅ Configuración del sistema

## Instalación

```bash
cd frontend
npm install
```

## Desarrollo

```bash
npm run dev
```

El frontend estará disponible en `http://localhost:3000`

## Build

```bash
npm run build
```

## Estructura

```
frontend/
├── src/
│   ├── components/     # Componentes reutilizables
│   ├── pages/         # Páginas principales
│   ├── services/      # Servicios API
│   └── App.tsx        # Componente principal
├── package.json
└── vite.config.ts
```

## Tecnologías

- **React 18** - Framework UI
- **TypeScript** - Tipado estático
- **Vite** - Build tool
- **TailwindCSS** - Estilos
- **React Router** - Navegación
- **Axios** - Cliente HTTP
- **Lucide React** - Iconos
